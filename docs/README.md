# Project docs

Central place for anything related to the CN360 PICO 4 VR project that
isn't code: meeting notes, design decisions, references, task
breakdowns. Keep it here instead of scattered across chats/drives so
the team has one source of truth.

Suggested layout as content accumulates:

- `meeting-notes/` — dated notes, one file per meeting
- `references.md` — links (PICO SDK docs, papers, assets)
- `decisions.md` — short log of key decisions and why they were made
