# ESP32 คุมกล้อง 2 แกนและไฟ 2 โหมด

ภาพแรกคือระบบทั้งหมดบนหุ่นจริง ภาพที่สองคือส่วน ESP32 ที่จำลองใน Tinkercad โดยใช้ Arduino Uno แทน ESP32 และใช้ Serial Monitor แทน Raspberry Pi ที่ส่งคำสั่ง `HEAD` / `LIGHT` ตามโปรโตคอลของโปรเจกต์

## ระบบทั้งหมดบนหุ่นจริง

คำสั่ง วิดีโอ ไฟเลี้ยง กรอบสีน้ำเงิน = มีในวงจร Tinkercad แล้ว ยังไม่ได้ต่อ

## Protocol ที่ใช้

ข้อความคำสั่งมีรูปแบบเดียวกันตลอดทาง (CN360 Command Protocol v1) ที่เปลี่ยนไปในแต่ละช่วงคือช่องทางที่ใช้ขนข้อความ

```
         WebSocket              UART                I2C
เว็บ ─────────────────▶ Pi ─────────────────▶ ESP32 ──────────▶ RoverC
     "HEAD,5,30,0,0"         "HEAD,5,30,0,0\n"      │  PWM
                                                    └──────────▶ servo / LED
```

### 1. รูปแบบข้อความ (ชั้นแอป)

```
DRIVE,<seq>,<linear>,<angular>,<speed_mode>
HEAD,<seq>,<yaw>,<pitch>,<roll>
LIGHT,<seq>,<brightness>,<vision_mode>
STATUS,<seq>,<battery_v>,<ack_seq>      ← Pi ส่งกลับไปที่เว็บ
```

| ตัวอย่างข้อความ | ทิศทาง | ความหมาย | ใน Tinkercad |
| --- | --- | --- | --- |
| DRIVE,101,0.50,0.00,1 | เว็บ → Pi → ESP32 | เดินหน้าครึ่งความเร็ว โหมดปกติ | ยังไม่ต่อ |
| DRIVE,102,0.00,-1.00,2 | เว็บ → Pi → ESP32 | หมุนตัวไปทางซ้ายเต็มแรง โหมด High Torque | ยังไม่ต่อ |
| DRIVE,103,0.00,0.00,1 | Pi → ESP32 | หยุด (Pi ส่งเองเมื่อเว็บหลุดเกิน 300 ms) | ยังไม่ต่อ |
| HEAD,104,30.00,-10.00,0.00 | เว็บ → Pi → ESP32 | กล้องหันขวา 30° และเงยขึ้น 10° | ✅ ใช้ได้ |
| HEAD,105,0,0,0 | เว็บ → Pi → ESP32 | กล้องกลับมาตรงกลาง | ✅ ใช้ได้ |
| LIGHT,106,80,0 | เว็บ → Pi → ESP32 | เปิดไฟส่องสว่าง 80 % | ✅ LED เหลือง |
| LIGHT,107,100,1 | เว็บ → Pi → ESP32 | สลับเป็นไฟ IR มองกลางคืน | ✅ LED แดง |
| STATUS,12,7.84,107 | Pi → เว็บ | แบต 7.84 V และได้รับคำสั่งล่าสุด seq 107 แล้ว | ไม่มี (ไม่มี Pi) |

| กติกา | ค่า |
| --- | --- |
| รูปแบบ | ข้อความ ASCII คั่นด้วยลูกน้ำ หนึ่งบรรทัดต่อหนึ่งคำสั่ง |
| อัตราส่ง | 20 ครั้ง/วินาที |
| seq | เพิ่มทีละ 1 ใช้ทิ้งคำสั่งเก่าและวัด ping |
| ทศนิยม | ใช้จุด `.` เสมอ |
| Failsafe | ไม่มีคำสั่งเกิน 300 ms → หยุด (ทั้งฝั่ง Pi และ ESP32) |

### 2. ช่องทางขนส่งคำสั่ง

| ช่วง | Protocol | รายละเอียด |
| --- | --- | --- |
| เว็บ → Pi | WebSocket | บน TCP/IP ผ่าน Wi-Fi, path `/ws`, HTTPS พอร์ต 8443, 1 ข้อความต่อ 1 frame |
| Pi → ESP32 | UART | 115200 baud 8N1, GPIO14/15 ↔ ESP32 UART2, ปิดท้ายบรรทัดด้วย `\n` |
| ESP32 → RoverC | I2C | address `0x38`, register `0x00`–`0x03` = ความเร็ว 4 ล้อ |
| ESP32 → servo | PWM | 50 Hz ความกว้างพัลส์บอกมุม |
| ESP32 → LED | PWM | duty cycle บอกความสว่าง 0–100 % |

### 3. วิดีโอ (แยกจากคำสั่ง)

| ช่วง | Protocol |
| --- | --- |
| กล้อง → Pi | CSI |
| Pi → MediaMTX | RTSPS (H.264) |
| MediaMTX → เว็บ | WebRTC (WHEP) |

ใน Tinkercad ข้อความที่พิมพ์ใน Serial Monitor คือข้อความเดียวกับที่ Pi จะส่งให้ ESP32 ทาง UART จริงทุกตัวอักษร

## วงจรใน Tinkercad (ส่วน ESP32)

5V GND สัญญาณ servo (เขียว) D5 (เหลือง) D6 (ม่วง) ยังไม่ต่อ A = Anode (ขางอ), K = Cathode (ขาตรง)

## ตารางขา

| ขา ESP32 | ต่อกับ | หน้าที่ | คำสั่งทดสอบ |
| --- | --- | --- | --- |
| D9 | Signal ของ Servo Pan | หมุนกล้องซ้าย-ขวา | HEAD,1,45,0,0 |
| D10 | Signal ของ Servo Tilt | ก้ม-เงยกล้อง | HEAD,2,0,-30,0 |
| D5 | 220Ω → Anode ของ LED เหลือง | ไฟส่องสว่าง | LIGHT,3,100,0 |
| D6 | 220Ω → Anode ของ LED แดง | ไฟ IR (มองกลางคืน) | LIGHT,4,100,1 |
| 5V | ราง + → Power ของ servo ทั้ง 2 ตัว | ไฟเลี้ยง |  |
| GND | ราง − → Ground ของ servo, Cathode ของ LED | กราวด์ร่วม |  |

บนหุ่นจริง ไฟจะผ่าน MOSFET เพราะ LED กำลังสูงกินกระแสมากกว่าที่ขาของ ESP32 จ่ายได้ ส่วน servo จะใช้ไฟ 5V แยกจากบอร์ด

## คำสั่ง servo: HEAD

พิมพ์ใน Serial Monitor แล้วกด Send ทีละบรรทัด คั่นด้วยลูกน้ำ ไม่เว้นวรรค ตัวพิมพ์ใหญ่

```
HEAD,<seq>,<yaw>,<pitch>,<roll>
```

| ช่อง | ความหมาย | ช่วงค่า | ไปที่ |
| --- | --- | --- | --- |
| seq | ลำดับคำสั่ง ใส่เลขอะไรก็ได้ | 1, 2, 3 … | ต้องใส่ให้ครบช่อง |
| yaw | หันซ้าย-ขวา · บวก = ขวา, ลบ = ซ้าย | −90 … 90 | Servo การหัน (D9) |
| pitch | ก้ม-เงย · บวก = ก้ม, ลบ = เงย | −45 … 45 | Servo การเงย (D10) |
| roll | เอียงหัว (ยังไม่มี servo) | 0 | — |

| พิมพ์ | ผลที่เห็น |
| --- | --- |
| HEAD,1,0,0,0 | กล้องตั้งตรงกลาง |
| HEAD,2,45,0,0 | หันขวา 45° |
| HEAD,3,-90,0,0 | หันซ้ายสุด |
| HEAD,4,0,-30,0 | เงยขึ้น 30° |
| HEAD,5,30,20,0 | หันขวา 30° และก้มลง 20° พร้อมกัน |

ใส่ค่าเกินช่วง โค้ดจะตัดให้อยู่ในช่วงเอง เช่น yaw = 200 จะได้ 90

## คำสั่งไฟ: LIGHT

```
LIGHT,<seq>,<ความสว่าง>,<โหมด>
```

| ช่อง | ความหมาย | ช่วงค่า |
| --- | --- | --- |
| seq | ลำดับคำสั่ง ใส่เลขอะไรก็ได้ | 1, 2, 3 … |
| ความสว่าง | เปอร์เซ็นต์ความสว่าง | 0 … 100 |
| โหมด | **0** = ไฟส่องสว่าง (LED เหลือง, D5) **1** = มองกลางคืน (LED แดงแทน IR, D6) | 0 / 1 |

| พิมพ์ | ผลที่เห็น |
| --- | --- |
| LIGHT,1,100,0 | LED เหลืองติดสว่างสุด |
| LIGHT,2,30,0 | LED เหลืองหรี่เหลือ 30 % |
| LIGHT,3,100,1 | LED เหลืองดับ LED แดงติดแทน |
| LIGHT,4,0,0 | ไฟดับทั้งหมด |

ติดได้ทีละดวง สั่งโหมดหนึ่งแล้วอีกดวงจะดับเอง

## ถ้าสั่งแล้วไม่มีอะไรเกิดขึ้น

| Serial Monitor ขึ้นว่า | สาเหตุ |
| --- | --- |
| HEAD -> pan … LIGHT -> … | โค้ดรับคำสั่งแล้ว ถ้าอุปกรณ์ไม่ขยับหรือไม่ติด ให้เช็กสาย |
| ignored: HEAD | ใส่ค่าไม่ครบช่อง (HEAD ต้องมี 5 ช่อง, LIGHT ต้องมี 4 ช่อง) |
| ignored: head | พิมพ์ตัวเล็ก ต้องเป็น HEAD / LIGHT ตัวพิมพ์ใหญ่ |
| ไม่ขึ้นอะไรเลย | ยังไม่ได้กด Start Simulation |
