# CN360 — รายการอุปกรณ์ (BOM)

- ฐานหุ่นใช้ **M5Stack RoverC** (HAT) แทนแชสซี + มอเตอร์ + ล้อ ที่วางไว้ใน BOM เดิม (`docs/robot 1.5.txt`)
- **Raspberry Pi บอร์ดเดียว** คุม RoverC (I2C), ไฟ LED ACT บนบอร์ด Pi และวัดแบต (ADS1115) เอง failsafe ชั้น 2 คือ RoverC ที่หยุดล้อเองเมื่อ I2C เงียบ (ดู [`system-design.md`](system-design.md) ข้อ 4)
- กล้องเปลี่ยนจาก pan/tilt เป็น **กล้องหน้า + กล้องหลังติดตาย** (ดู [`system-design.md`](system-design.md) ข้อ 10) จุดที่กล้องมองไม่เห็นใช้การหมุนหุ่นด้วย thumbstick
- ราคาเป็นช่วงประมาณ ควรเช็คราคาจริงก่อนสั่งซื้อ

## การต่อสาย (สรุป)

```
แบต 2S ─ BMS ─ สวิตช์/ฟิวส์ ─┬─ Buck 5V 3A ──→ Raspberry Pi 4B ─── USB  → กล้องหลัง
                            └─ 100k/33k ──→ ADS1115 A0

แบต 16340 ในตัว RoverC ──→ มอเตอร์ N20 ×4   (รางไฟมอเตอร์แยกจาก Pi)

Pi CSI                        ← กล้องหน้า Camera Module 3
Pi GPIO2/3 (I2C bus 1)        ↔ RoverC                    (address 0x38)
                              ↔ ADS1115                   (address 0x48, VDD = Pi 3.3 V)

GND ทุกส่วน (แบต 2S, Pi, ADS1115, RoverC) ต้องต่อร่วมกัน
```

ขา GPIO จริงของ Pi ให้บันทึกไว้ใน `Docs/pi-pinout.md` (ร่างอยู่ใน `system-design.md` ข้อ 7)

## ข้อควรระวัง

- **น้ำหนัก:** RoverC ออกแบบมาให้แบก M5StickC ตัวเล็ก ๆ ส่วน Pi 4B + แบต 2S + กล้อง 2 ตัว หนักรวมประมาณ 250–350 g ต้องลองวิ่งจริงก่อนว่ามอเตอร์ N20 ของ RoverC รับไหว ถ้าไม่ไหว ทางเลือกคือเปลี่ยนเป็น Raspberry Pi Zero 2 W หรือใช้แบตก้อนเล็กลง
- **ระบบขับเคลื่อนเปลี่ยน:** `plan.md` Phase 4 เขียนไว้ว่าใช้ TB6612FNG + differential drive แต่ RoverC รับคำสั่งความเร็วล้อทั้ง 4 ผ่าน I2C Pi ต้องแปลง `DRIVE` (linear, angular) เป็นความเร็วล้อ mecanum 4 ล้อ
- **Failsafe:** ทดสอบแล้วว่า RoverC หยุดล้อเองเมื่อ I2C เงียบ (H-2) แต่ยังต้องวัดว่าใช้เวลากี่ ms ฝั่ง Pi ต้องเขียน 0 เองเมื่อ WebSocket หลุดหรือไม่มี `DRIVE` เกิน 300 ms และต้องมีสวิตช์ตัดไฟหลักเสมอ
- **แบตในตัว RoverC (16340 700 mAh):** ปกติชาร์จผ่าน M5StickC เมื่อไม่ใช้ M5StickC ให้ถอดก้อนออกมาชาร์จด้วยแท่นชาร์จ 16340 ภายนอก
- **ระดับแรงดัน I2C:** วัดก่อนว่าขา SDA/SCL ที่ HAT header ของ RoverC เป็น 3.3 V (GPIO ของ Pi ทนได้แค่ 3.3 V ถ้า RoverC ดึง pull-up ไป 5 V ต้องใส่ level shifter)
- **มุมกล้องที่ร้านเขียน** มักเป็นแนวทแยง ถามร้านว่ามุมแนวนอนของกล้องหลังเท่าไร
