- กล้องเปลี่ยนจาก pan/tilt เป็น **กล้องหน้า + กล้องหลังติดตาย** (ดู [`system-design.md`](system-design.md) ข้อ 10) จุดที่กล้องมองไม่เห็นใช้การหมุนหุ่นด้วย thumbstick

## การต่อสาย (สรุป)

```
แบต 2S ─ BMS ─ สวิตช์/ฟิวส์ ─┬─ Buck 5V 3A ──→ Raspberry Pi 4B ─┬─ USB  → กล้องหลัง
                            │                                  └─ 5V pin → ESP32
                            ├─ ตัวจำกัดกระแส ─ LED ขาว ─ MOSFET ─ GND
                            └─ 100k/33k ──→ ESP32 ADC

แบต 16340 ในตัว RoverC ──→ มอเตอร์ N20 ×4   (รางไฟมอเตอร์แยกจาก Pi)

Pi CSI                        ← กล้องหน้า Camera Module 3
Raspberry Pi GPIO14/15 (UART) ↔ ESP32 UART2 (GPIO16/17)   115200 baud
ESP32 SDA/SCL (I2C)           ↔ RoverC                    (address 0x38)
ESP32 PWM                     → gate MOSFET (LED ขาว)
ESP32 ADC                     ← ตัวแบ่งแรงดันจากแบต 2S

GND ทุกส่วน (แบต 2S, Pi, ESP32, RoverC, MOSFET) ต้องต่อร่วมกัน
```

ขา GPIO จริงของ ESP32 ให้บันทึกไว้ใน `Docs/esp32-pinout.md`

## ข้อควรระวัง

- **น้ำหนัก:** RoverC ออกแบบมาให้แบก M5StickC ตัวเล็ก ๆ ส่วน Pi 4B + แบต 2S + กล้อง 2 ตัว + LED หนักรวมประมาณ 250–350 g ต้องลองวิ่งจริงก่อนว่ามอเตอร์ N20 ของ RoverC รับไหว ถ้าไม่ไหว ทางเลือกคือเปลี่ยนเป็น Raspberry Pi Zero 2 W หรือใช้แบตก้อนเล็กลง
- **ระบบขับเคลื่อนเปลี่ยน:** `plan.md` Phase 4 เขียนไว้ว่าใช้ TB6612FNG + differential drive แต่ RoverC รับคำสั่งความเร็วล้อทั้ง 4 ผ่าน I2C ต้องแก้ firmware ESP32 ให้แปลง `DRIVE` (linear, angular) เป็นความเร็วล้อ mecanum 4 ล้อ
- **Failsafe:** ESP32 ต้องสั่ง RoverC ให้ความเร็วล้อเป็น 0 เองเมื่อไม่ได้รับคำสั่งทาง serial เกิน 300 ms — ยังไม่พบว่าบอร์ด STM32 ของ RoverC หยุดล้อเองเมื่อ I2C เงียบ ถ้า ESP32 ค้าง ล้ออาจหมุนต่อ ต้องทดสอบ และต้องมีสวิตช์ตัดไฟหลักเสมอ
- **แบตในตัว RoverC (16340 700 mAh):** ปกติชาร์จผ่าน M5StickC เมื่อไม่ใช้ M5StickC ให้ถอดก้อนออกมาชาร์จด้วยแท่นชาร์จ 16340 ภายนอก
- **ระดับแรงดัน I2C:** วัดก่อนว่าขา SDA/SCL ที่ HAT header ของ RoverC เป็น 3.3 V (ESP32 ทนได้แค่ 3.3 V)
- **มุมกล้องที่ร้านเขียน** มักเป็นแนวทแยง ถามร้านว่ามุมแนวนอนของกล้องหลังเท่าไร
